# riyakadakia.github.io

Plain HTML/CSS personal site — no build step. Edit the .html files directly.

- `index.html` — About + News
- `cv.html`, `publications.html`, `classes.html`
- `projects.html` — project list; each project has a page in `projects/`
- `images/` — drop `headshot.jpg` here; replace `placeholder.svg` references with real project images
- `style.css` — all styling

To publish: push to the repo, then Settings → Pages → Deploy from branch → `main` / root.
